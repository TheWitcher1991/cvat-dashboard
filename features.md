# Возможные улучшения

- [ ] Поиск по имени/username пользователя
- [ ] Фильтр карточек по количеству задач/проектов/джобов
- [ ] Фильтр по статусу (активные/завершённые)

## Сортировка
- [ ] Сортировка карточек: по имени, задачам, проектам, джобам, кадрам
- [ ] Сохранение выбранной сортировки

## Экспорт
- [ ] Экспорт статистики группы в CSV

- [ ] Прогресс-бары выполнения по проектам
- [ ] Спарклайны (мини-графики) на карточках пользователей

## Данные

- [ ] WebSocket / live-обновления при изменениях в CVAT
- [ ] Кэширование ответов CVAT (сократить время загрузки)
